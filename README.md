# SERA — Restaurant Demo

## Overview
An editorial restaurant landing page focused on typography, mobile menu UX and a frictionless demo reservation flow.

## Features
- Responsive editorial layout
- Filterable menu with demo prices
- Accessible reservation modal and success state
- SEO, Open Graph metadata and custom favicon

## Stack
- Next.js
- React
- TypeScript
- CSS

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```
