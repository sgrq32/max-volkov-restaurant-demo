# SERA — Restaurant Demo

![Screenshot placeholder](./docs/screenshot-placeholder.png)

A fictional premium restaurant landing page focused on typography, mobile menu UX and a frictionless demo reservation flow.

## Features
- Responsive editorial layout
- Filterable menu with demo prices
- Accessible reservation modal and success state
- SEO/Open Graph metadata and custom favicon

## Stack
Next.js 16 · React 19 · TypeScript · CSS

## Local development
```bash
npm install
npm run dev
```

## Build & deploy
```bash
npm run build
npx vercel --prod
```
